📌 О проекте

«САЛЮТ» — полнофункциональный веб-чат с искусственным интеллектом, построенный на современном стеке технологий. Проект демонстрирует передовой подход к разработке фронтенда в рамках дисциплины «Проектная деятельность».

⚡ Ключевые возможности

  • Чат с ИИ — создание, переименование и удаление чатов, стриминг ответов в реальном времени
  • Работа с файлами — поддержка PDF, изображений, TXT, DOCX, XLSX, CSV, JSON с извлечением текста
  • Предпросмотр PDF — постраничный просмотр с зумом прямо в браузере
  • Анализ изображений — через vision-возможности модели ИИ
  • Долгосрочная память — запоминание фактов и предпочтений пользователя
  • Системные промпты — гибкая настройка поведения модели
  • Тёмная/светлая тема — с плавным переключением
  • Адаптивный дизайн — от 320px до 4K в стиле Apple
⚛️ Next.js 16 ⚛️ React 18 🎨 CSS Modules 🧠 Claude API 📄 PDF.js

📔 Журнал проекта

Этапы разработки ИИ-ассистента «САЛЮТ»

🗓️ 25 марта 2025

Спринт 1: Архитектура и базовая реализация чата

Развёрнут Next.js проект, настроен маршрутизатор App Router. Реализован базовый интерфейс чата с возможностью отправки сообщений и стримингом ответов от ИИ. Протестирована интеграция с Claude API.

✅ Завершено: 100%
📄 10 апреля 2025

Спринт 2: Интеграция PDF и файловой системы

Добавлена поддержка загрузки файлов через drag-and-drop. Реализован парсинг PDF через PDF.js с извлечением текста. Создан компонент предпросмотра PDF с постраничной навигацией и зумом.

✅ Завершено: 95%
🧠 5 мая 2025

Спринт 3: Память, промпты и финальная полировка

Реализована система долгосрочной и краткосрочной памяти с сохранением в localStorage. Добавлена возможность настройки пользовательского системного промпта. Выбрана тёмная и светлая тема. Проект готов к демонстрации!

✅ Завершено: 100%
