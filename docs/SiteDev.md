# Отчёт по проекту веб-сайта «ЭкоПульс»

## Общая информация

Проект «ЭкоПульс» представляет собой статический веб-сайт, разработанный на HTML5 и CSS3 в рамках дисциплины «Проектная деятельность». Основная цель сайта — презентация экологического проекта, связанного с мониторингом состояния городской среды и развитием зелёной инфраструктуры.

Сайт выполнен в современном адаптивном стиле с акцентом на экологическую тематику. Визуальная концепция построена на сочетании зелёных и светлых оттенков, что подчёркивает тематику устойчивого развития и экологической безопасности.

---

# Используемые технологии

## HTML5

HTML используется для построения структуры веб-страницы. В проекте реализованы:

- семантические теги (`header`, `main`, `section`, `footer`);
- навигационное меню;
- карточки контента;
- медиа-элементы;
- встроенные SVG-заглушки;
- адаптивная структура разделов.

## CSS3

CSS отвечает за оформление и адаптивность интерфейса. Использованы:

- Flexbox;
- CSS Grid;
- CSS Variables (`:root`);
- медиазапросы (`@media`);
- плавные анимации и hover-эффекты;
- тени и скругления;
- линейные градиенты.

# Особенности CSS-оформления

## Глобальный сброс стилей

В начале файла используется универсальный селектор:

```css
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
```

Это позволяет избежать различий отображения элементов в разных браузерах.

---

## CSS-переменные

В проекте применяются пользовательские переменные:

```css
:root {
    --primary: #2f6b47;
    --secondary: #e9b35f;
}
```

Преимущества:
- единая цветовая схема;
- удобство редактирования;
- повышение читаемости кода.

---

## Адаптивная вёрстка

Для адаптации сайта под мобильные устройства используется медиазапрос:

```css
@media (max-width: 750px)
```

На небольших экранах:
- уменьшается размер заголовков;
- элементы выстраиваются вертикально;
- центрируется навигация;
- упрощается структура блоков.

---

## Flexbox и Grid

Для построения сетки применяются современные технологии.

### Flexbox

Используется в:
- шапке сайта;
- hero-блоке;
- карточках участников;
- блоках ресурсов.

### CSS Grid

Используется в разделе журнала проекта:

```css
.journal-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
}
```

Это обеспечивает автоматическое распределение карточек по ширине экрана.
