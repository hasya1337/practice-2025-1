# Отчёт по проекту веб-сайта «САЛЮТ»

## Общая информация

Проект «САЛЮТ» представляет собой современный веб-сайт ИИ-ассистента, разработанный в рамках дисциплины «Проектная деятельность». Основная задача проекта — создание интеллектуального чат-бота с поддержкой анализа файлов, долгосрочной памяти и гибкой настройки взаимодействия с пользователем.

Сайт выполнен в современном стиле Glassmorphism с использованием градиентов, полупрозрачных элементов и адаптивного интерфейса. Визуальная концепция вдохновлена дизайном Apple и современными AI-платформами.

---

# Используемые технологии

## HTML5

HTML используется для создания структуры сайта. В проекте реализованы:

- семантические теги (`header`, `main`, `section`, `footer`);
- адаптивная навигация;
- карточки контента;
- секции с журналом проекта;
- блоки демонстрации чата;
- встроенные SVG-заглушки;
- медиа-компоненты и видео.

---

## CSS3

CSS отвечает за визуальное оформление и адаптивность интерфейса.

В проекте используются:

- Flexbox;
- CSS Grid;
- CSS Variables (`:root`);
- Glassmorphism-эффекты;
- медиазапросы (`@media`);
- градиенты (`linear-gradient`);
- анимации (`@keyframes`);
- backdrop-filter blur;
- hover-эффекты и плавные переходы.

# Особенности CSS-оформления

## Глобальный сброс стилей

В начале CSS-файла применяется универсальный селектор:

```css
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
```

Это обеспечивает единое отображение элементов во всех браузерах.

---

## CSS-переменные

Для удобства настройки дизайна используются переменные:

```css
:root {
    --primary: #5850e8;
    --primary-dark: #3f38b5;
    --primary-light: #8b5cf6;
}
```

Преимущества:
- централизованное управление цветами;
- упрощение поддержки проекта;
- повышение читаемости кода.

---

## Glassmorphism-дизайн

Одной из ключевых особенностей проекта является использование эффекта Glassmorphism.

Пример:

```css
.site-header {
    background: rgba(255, 255, 255, 0.8);
    backdrop-filter: blur(20px);
}
```

Эффект создаёт:
- полупрозрачные элементы;
- ощущение глубины интерфейса;
- современный визуальный стиль.

# Использование Flexbox и Grid

## Flexbox

Flexbox применяется для:
- шапки сайта;
- hero-секции;
- карточек интерфейса;
- адаптивного расположения блоков.

Пример:

```css
.hero-grid {
    display: flex;
    flex-wrap: wrap;
    gap: 40px;
}
```

---

## CSS Grid

Grid используется для:
- карточек участников;
- журнала проекта;
- адаптивной сетки контента.

Пример:

```css
.members-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
}
```

# Анимации и эффекты

Используются:
- CSS transitions;
- box-shadow;
- transform;
- backdrop-filter;
- keyframes-анимации.

Пример анимации:

```css
@keyframes blink {
    0%, 100% { opacity: 1; }
    50% { opacity: 0; }
}
```

Эта анимация используется для эффекта «печати» ответа ИИ.
